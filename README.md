**Diyarbakır Life** is an open-source, community-driven smart city guide and local utility mobile application built with Flutter. It connects local citizens, visitors, and businesses with real-time public utilities, verified news, classifieds, and municipal services in a unified, modern mobile experience.

---

## ✨ Features

- **🏥 On-Duty Pharmacies (Nöbetçi Eczaneler):** Live daily updates of on-duty pharmacies with phone calling, Google Maps navigation, and distance sorting.
- **📢 Community Classifieds (İlanlar):** Free classified listings for real estate, vehicles, second-hand goods, and local job opportunities.
- **⛅ Real-time Weather:** Accurate regional weather forecasts with alerts.
- **🏢 Local Business Directory:** Searchable catalog of local vendors, restaurants, and craftsmen with one-touch contact.
- **📰 Regional News Feed:** Curated local news updates covering regional events and municipal announcements.
- **📍 District Personalization:** Tailored content based on selected districts (Kayapınar, Bağlar, Yenişehir, Sur, Bismil, Ergani, etc.).

---

## 🛠️ Tech Stack & Architecture

- **Framework:** Flutter & Dart
- **State Management:** Riverpod 2.x
- **Routing:** GoRouter
- **Backend & Cloud:** Firebase Core, Cloud Firestore, Firebase Auth, Firebase Cloud Messaging (FCM)
- **Local Storage:** SharedPreferences
- **Design System:** Material 3 with adaptive Dark/Light modes

## 🚀 Getting Started

### Prerequisites
- [Flutter SDK](https://docs.flutter.dev/get-started/install) (>= 3.2.0)
- Xcode (for iOS builds) / Android Studio (for Android builds)
- A configured Firebase project (google-services.json and GoogleService-Info.plist)

### Installation

1. Clone the repository:
   `ash
   git clone https://github.com/ongorenmuhammet/-diyarbakir-life.git
   cd -diyarbakir-life
   `

2. Install dependencies:
   `ash
   flutter pub get
   `

3. Run the development build:
   `ash
   flutter run
   `
